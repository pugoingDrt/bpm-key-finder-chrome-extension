# BPM & Key Finder – Tap Tempo (Chrome Extension)

[![Chrome Web Store](https://img.shields.io/badge/Chrome%20Web%20Store-Install%20Free-4285F4?style=flat-square&logo=googlechrome&logoColor=white)](https://chromewebstore.google.com/detail/bpm-key-finder-%E2%80%93-tap-temp/lpklajhjhmkibgkkegfblldapdmmkjmm)
[![Privacy: 100% Local](https://img.shields.io/badge/Privacy-100%25%20Local-14b8a6?style=flat-square)](https://removebackgroundmusic.app/privacy-policy)

A fast, free Chrome extension for DJs, music producers, and video editors to find the **BPM (tempo)**, **musical key**, and **Camelot wheel code** of any song directly on your computer — plus an instant **Tap Tempo** tool.

Everything runs **100% locally in your browser**: your audio files never leave your device.

👉 **[Install BPM & Key Finder on the Chrome Web Store](https://chromewebstore.google.com/detail/bpm-key-finder-%E2%80%93-tap-temp/lpklajhjhmkibgkkegfblldapdmmkjmm)**

---

## Key Features

- **Instant BPM & Tempo Detection**: Accurately measure beats per minute for DJ beatmatching, remixing, and video sync.
- **Musical Key & Camelot Code**: Identify both standard musical keys (e.g., `A Minor`, `C Major`) and **Camelot wheel notation** (e.g., `8A`, `8B`) for smooth harmonic mixing.
- **Built-in Tap Tempo**: Tap along to any track or beat in real time to calculate BPM instantly.
- **100% Local & Private**: Zero file uploads — all audio analysis runs locally inside Chrome.
