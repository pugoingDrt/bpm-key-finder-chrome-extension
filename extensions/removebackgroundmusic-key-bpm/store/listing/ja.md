- 概要：パソコン内の曲のBPM・キー・Camelotコードを判定。タップテンポ付き。無料で、ファイルはアップロードされず端末内で処理します。

## Description (paste into the store)

「BPM・キー判定」は、パソコンにあるトラックのテンポ（BPM）と調を数秒で調べる拡張機能です。MP3・WAV・M4A・FLAC・OGG、さらに動画ファイルをドロップするだけで、次の結果がわかります。

• 調：「Aマイナー」など。平行調も表示
• Camelotコードと Open Key 表記：ハーモニックミックスに
• BPM：テンポと、その半分・倍の値
• 相性の良い調：Camelotホイールで隣り合うもの。DJのつなぎに便利

まとめて解析
複数のトラックやフォルダごと、一度にドロップできます。1曲ずつ順番に解析し、結果はコピーしたり、CSVファイルでダウンロードしてDJライブラリやメモに使えます。

タップテンポ付き
手元にファイルがないときは、ビートに合わせてボタンかTキーを押せば、その場でテンポを測れます。

プライバシーに配慮
処理はすべてブラウザ内で行われます。ファイルはアップロードされず、何も保存されません。拡張機能は権限を一切求めないため、閲覧中のウェブサイトを読み取ることもできません。

こんな方に
DJセットを準備するDJ、合うサンプルを探すトラックメイカー、何を弾けばいいか知りたいボーカリストや演奏者、リミックス・マッシュアップ・耳コピをする方に。

使い方
1. 拡張機能のアイコンをクリックすると、タブで開きます。
2. トラックをページにドロップするか、クリックしてファイルを選びます。
3. 結果を確認、またはコピーします。

10分までのトラックに対応しています。結果は音声からの推定です。テンポが変わる曲や珍しい和声の曲は、耳でもご確認ください。

Camelot と Open Key はDJソフトで使われる表記です。本拡張機能はそれらの権利者とは関係ありません。

提供：Remove Background Music（removebackgroundmusic.app）。当サイト（英語）には、曲からBGMを消す、ステムに分ける、MIDIに変換するツールもあります（一部は有料クレジットを使います）。
