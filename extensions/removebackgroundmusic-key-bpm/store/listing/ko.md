- 이름: BPM 및 키 찾기 – 탭 템포
- 요약: 내 컴퓨터에 있는 노래의 BPM, 키, Camelot 코드를 찾아 줍니다. 탭 템포 포함. 무료이며 파일은 업로드되지 않고 기기에서 처리됩니다.
- 스크린샷: `images/screenshot-1-results-ko.png`

## Description (paste into the store)

BPM 및 키 찾기는 내 컴퓨터에 있는 트랙의 템포(BPM)와 조성을 몇 초 만에 알려 줍니다. MP3, WAV, M4A, FLAC, OGG 파일은 물론 동영상 파일도 놓기만 하면 다음 결과를 볼 수 있습니다.

• 조성: 예를 들어 "A 마이너"와 나란한조
• Camelot 코드와 Open Key 표기: 하모닉 믹싱용
• BPM: 템포와 그 절반·두 배 값
• 잘 어울리는 조성: Camelot 휠에서 이웃한 것으로, 자연스러운 DJ 전환에 도움

한 번에 여러 곡 분석
여러 트랙이나 폴더 전체를 한꺼번에 놓으세요. 한 곡씩 차례로 분석하며, 결과를 복사하거나 CSV 파일로 내려받아 DJ 라이브러리나 메모에 활용할 수 있습니다.

탭 템포 내장
파일이 없나요? 박자에 맞춰 버튼이나 T 키를 누르면 바로 템포가 표시됩니다.

개인 정보 보호
모든 처리는 브라우저 안에서 이루어집니다. 파일은 업로드되지 않고 아무것도 저장되지 않습니다. 확장 프로그램은 어떤 권한도 요청하지 않으므로 방문하는 웹사이트를 읽을 수 없습니다.

이런 분께 추천
세트를 준비하는 DJ, 어울리는 샘플을 찾는 프로듀서, 무엇을 연주할지 알고 싶은 가수와 연주자, 리믹스·매시업을 만들거나 음악에 맞춰 연습하는 모든 분.

사용 방법
1. 확장 프로그램 아이콘을 클릭하면 탭에서 열립니다.
2. 트랙을 페이지에 놓거나 클릭해 파일을 선택합니다.
3. 결과를 확인하거나 복사합니다.

10분 이하의 트랙을 지원합니다. 결과는 오디오로부터의 추정치이므로, 템포가 바뀌거나 화성이 독특한 곡은 귀로도 확인해 주세요.

Camelot과 Open Key는 DJ 소프트웨어에서 쓰이는 표기법이며, 이 확장 프로그램은 그 권리자와 관련이 없습니다.

제작: Remove Background Music(removebackgroundmusic.app). 저희 웹사이트(영어)에는 노래에서 배경 음악 제거, 스템 분리, MIDI 변환 도구도 있습니다(일부는 유료 크레딧 사용).
